Sample Superstore Sales & Profit Analysis (EDA)

# Project Overview
 
This project focuses on Exploratory Data Analysis (EDA) of the Sample Superstore dataset to identify profitability patterns, loss-making products, and regional performance.
The goal is to support data-driven business decisions using visualization and statistical insights.

#Objectives

Analyze sales, profit, and discount patterns
Identify loss-making categories, sub-categories, and states
Provide business recommendations based on insights

Dataset Description

The dataset contains retail transaction records with the following features:
Sales
Profit
Discount
Category / Sub-Category
State / City / Region

#Tools & Technologies Used

Python
Pandas & NumPy – Data cleaning & manipulation
Matplotlib & Seaborn – Static visualizations
Plotly – Interactive charts
Jupyter Notebook / Kaggle

#Steps Performed

 Data Cleaning
Removed duplicate records
Dropped irrelevant columns (Country, Postal Code)
Checked data types and missing values
 Exploratory Data Analysis
Category-wise Sales & Profit analysis
Sub-Category profit comparison
State and City-level profit distribution

# Visualization
 
Correlation heatmap
Bar charts for profit comparison
Pie charts for sales & profit contribution
Scatter plots to identify loss zones

# Key Insights
 
Technology category generated the highest profit
Furniture showed losses in several sub-categories
High discounts negatively impacted profit
Corporate and Consumer segments contributed most to sales

 # Business Recommendations
 
Reduce excessive discounts on loss-making sub-categories
Re-evaluate pricing strategy for Furniture items
Focus marketing efforts on high-profit states
